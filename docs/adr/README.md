# Registros de decisão de arquitetura (ADR)

Decisões que valem para a **suíte inteira** — Tezzet e TAPS — moram aqui, neste repositório, ao lado de `suite/`, que é o espaço unificado de marca, narrativa e tokens dos dois produtos.

Uma ADR registra o que foi decidido, quando, por quem, **quais alternativas foram rejeitadas e por quê**, e o que teria que ser verdade para voltar atrás. Ela não é substituída no lugar: quando uma decisão muda, escreve-se uma nova ADR que declara qual ela substitui.
